# Security

This repository is an unsupported research experiment by [IsoKron](https://isokron.ai), based on
`@payloadcms/plugin-mcp` 3.93.0. It is not an official Payload release, it receives no security updates, and it is not
meant for production use.

**Do not run it against data you care about.** If you run it at all, use a disposable local Payload app, test users
and a throwaway database, listening on 127.0.0.1 only, as the harness does.

## Reporting

- **Vulnerabilities in the official Payload plugin** (anything that also exists upstream): report them to Payload
  through the official project's security policy
  ([SECURITY.md](https://github.com/payloadcms/payload/blob/main/SECURITY.md)), not here.
- **Problems specific to the experimental changes** in this repository (see
  [CHANGES-EXPERIMENT.md](CHANGES-EXPERIMENT.md)): email hello@isokron.ai, or open an issue here if the problem is not
  sensitive.

Reports are read, but no response time or fix is promised.
