# Support

No support is offered for this repository. It is a research experiment by [IsoKron](https://isokron.ai), kept so the
changes can be inspected and the measurement reproduced. See [EXPERIMENT.md](EXPERIMENT.md).

- **Your reproduction disagrees with ours:** please open an issue with the task, model, client version and counts
  (runs correct, tool calls, tokens). These reports are welcome.
- **Help using Payload or its MCP plugin:** use the official project,
  [payloadcms/payload](https://github.com/payloadcms/payload). This repository is not affiliated with Payload CMS, Inc.

This build is based on upstream v3.93.0 and is not maintained against later upstream versions.
