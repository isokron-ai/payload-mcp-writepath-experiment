# Statistics: research vs baseline

110 runs. Intervals are 95%. Bootstrap: 10000 task resamples, seed 1 (rerun with the same seed for the same numbers). pass@k and pass^k use k = the fewest runs any task has unless --k is given. Sets are reported separately and never pooled. Generated by IsoKron's internal statistics script (not public); the method is as stated here.

> **Scope note (added 13 Nov 2026).** These statistics cover all six set A tasks, **including A3**. A3's prompt file was a copy of U3's at the explore freeze; the bench dry run caught it, and A3 is reported in the friction-derived set, not the pre-registered set (see [BENCHMARK.md](BENCHMARK.md), "Corrected 13 November 2026"). The figures for the **five pre-registered tasks** (A3 excluded) are in [STATS-opus-preregistered.md](STATS-opus-preregistered.md): completion 9/25 → 24/25 (+60.0 pp [12.0, 100.0]); median tokens 34,365 → 40,709 (+6,344 [−7,445, 21,477], interval includes zero); exact sign test p = 0.375. Quote those, not this file, for the pre-registered comparison.
